# Global Layoffs Data Analysis

## Project Overview

This project analyzes global layoffs data using Python and Pandas to identify trends across years, industries, companies, countries, and company stages.

The main objective of this project was to practice:
- Data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization
- Working with real-world messy datasets

This project marks the completion of my foundational data analysis learning phase before transitioning toward more engineering-focused development.

---

## Dataset

The dataset contains information about company layoffs, including:
- Company name
- Industry
- Country
- Total employees laid off
- Funding raised
- Company stage
- Date of layoffs
